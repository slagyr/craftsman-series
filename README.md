# The Craftsman Series

This repository contains a Markdown edition of **The Craftsman**, a long-form series of software engineering articles by **Robert C. Martin (Uncle Bob)**, published from **February 2002 through November 2010**.

The series is written as a continuing story rather than a conventional textbook. It follows an apprentice programmer, the people around him, and the projects they work on together. Across the episodes, the narrative explores how professional developers think, how they learn, how they collaborate, and how they improve code under pressure.

Without spoiling the story, the series moves through several broad phases:

- early refactoring and unit testing lessons built around small programming exercises
- networked and command-line tools developed incrementally from user needs outward
- larger team-based project work where requirements, acceptance tests, architecture, and design pressure start to matter more
- technical side conversations and brown-bag discussions on language features, design tradeoffs, and programming style
- later essays that connect the story back to broader Clean Code and software craftsmanship ideas

What makes the series distinctive is the combination of:

- narrative storytelling
- code listings and incremental design changes
- practical lessons in TDD, refactoring, naming, decomposition, architecture, and team behavior
- a recurring emphasis on craftsmanship over mere code production

## Reading Order

The articles are intended to be read in numeric order, starting with `The Craftsman 01 primes.md` and continuing through `The Craftsman 63 Specifics and Generics.md`.

## Repository Layout

- top level: the Markdown versions of the articles
- `archive/`: original source material, HTML conversions, PDFs, zips, and supporting artifacts

## Note

The Markdown files are normalized reading copies converted from the original documents. They are designed to be searchable and easy to read, but they are not exact layout facsimiles of the source files.
